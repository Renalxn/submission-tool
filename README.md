# 投稿排版助手

面向中文纸媒投稿者的一键稿件排版工具。可以自动统一标题、作者与正文版式，统计正文字数，支持预置联系信息与稿费收款账号，帮助作者一键将稿件调整为报纸、杂志等纸质出版物的投稿规范格式，免去反复手动排版的繁琐工作。

## 功能特点

- **智能排版**：按投稿规范自动排版
- **自动识别**：从文件中识别标题、作者
- **字数统计**：自动统计正文字数
- **信息记忆**：联系信息和银行信息自动记忆
- **多格式支持**：支持 .docx / .txt / .md 输入
- **双格式输出**：同时生成 .docx 和 .txt
- **快捷键操作**：支持快捷键，提升效率
- **不联网**：纯本地运行，保护隐私

## 使用方法

1. 下载并运行 `投稿排版助手_v1.0.43.exe`
2. 首次运行时，会自动释放 `用户手册.txt` 到 exe 同级目录
3. 按照用户手册操作即可

### 使用方法

1. **选择文件**：点击"浏览文件"按钮，选择 .docx、.txt 或 .md 格式的文件
2. **选择保存文件夹**：点击"浏览文件夹"按钮，选择输出位置
3. **填写信息**：标题、作者会自动识别，也可手动修改
4. **排版并导出**：点击"排版并导出"按钮
5. **快捷键操作**：

| 快捷键 | 功能 |
|--------|------|
| Alt+B | 浏览文件 |
| Alt+L | 浏览文件夹 |
| Alt+G | 添加银行信息组 |
| Alt+X | 排版并导出 |
| Alt+D | 删除银行信息组 |
| 回车键 | 智能导航（输入框 → 下一个输入框 → 导出按钮） |
| 方向键 | 在各个输入框和按钮间切换 |
| Alt+O | 确定/覆盖（弹窗） |
| Alt+S | 另存为（弹窗） |
| Alt+C | 取消/关闭（弹窗） |

### 原始文件格式

如果您的原始文件符合以下结构，程序将自动识别标题和作者；否则请手动在相应输入框中修改：

```
第1行：文章标题
第2行：作者姓名
第3行起：正文内容
```

### 输出文件

在选择的保存目录下自动创建"《文章标题》投稿"文件夹，包含：
- `《文章标题》作者姓名.docx`
- `《文章标题》作者姓名.txt`

## 排版格式

- **标题**：宋体，4号（14磅），居中
- **作者**：宋体，5号（10.5磅），居中
- **正文**：宋体，5号（10.5磅），两端对齐，段首缩进2字符，单倍行距
- **字数统计**：自动统计正文字数（不含标题、作者、空行），在正文末尾显示"（正文：xxx 字）"，宋体，5号（10.5磅），右对齐
- **联系信息**：宋体，5号（10.5磅），左对齐
  - 包含：姓名、微信、电话、地址、邮编、身份证号、邮箱
- **银行信息**：宋体，5号（10.5磅），左对齐
  - 最多可添加4组
  - 每组包含：银行名称、账号、开户支行、联行号（选填）

## 数据安全

- 所有敏感信息（联系信息、银行信息）加密保存在本地
- 配置文件位置：`C:\Users\你的用户名\.tougao_assistant\`
- 不会上传到网络

## 开发者文档

### 从源码运行

```bash
# 安装依赖（已锁定版本）
pip install python-docx==1.1.0 cryptography==41.0.7

# 运行程序
python app.py
```

### 运行测试

```bash
# 运行单元测试
python -m unittest discover tests

# 运行单个测试文件
python -m unittest tests/test_app.py
```

### 打包为可执行文件

```bash
# 安装 PyInstaller（已锁定版本）
pip install pyinstaller==6.0.0

# Windows 打包
pyinstaller subtool.spec

# macOS 打包（需在 macOS 环境）
pyinstaller subtool_macos.spec

# Linux 打包（需在 Linux 环境）
pyinstaller subtool_linux.spec
```

> 注意：PyInstaller 不支持交叉编译，需在目标平台上打包。
