## 主要功能

### 核心功能
- 支持输入 .docx / .txt / .md 文件
- 自动识别标题、作者
- 按投稿规范排版（宋体、字号、对齐、行距）
- 自动统计正文字数
- 自动添加联系信息（姓名、微信、电话、地址、邮编、身份证号、邮箱）
- 自动添加银行信息（最多4组，每组包含银行名称、账号、开户支行、联行号）
- 同时生成 .docx 和 .txt 两种格式
- 支持快捷键操作，提升效率

### 数据安全
- 不联网，纯本地运行
- 联系信息和银行信息加密保存
- 保护用户隐私

### 排版格式
- **标题：** 宋体，4号，居中
- **作者：** 宋体，5号，居中
- **正文：** 宋体，5号，两端对齐，段首缩进2字符，单倍行距
- **字数统计：** 自动统计正文字数（不含标题、作者、空行），在正文末尾显示"（正文：xxx 字）"，宋体，5号，右对齐
- **联系信息：** 宋体，5号，左对齐（包含7项信息）
- **银行信息：** 宋体，5号，左对齐（最多4组）

### 快捷键操作

| 快捷键 | 功能 |
|--------|------|
| Alt+B | 浏览文件 |
| Alt+L | 浏览文件夹 |
| Alt+G | 添加银行信息组 |
| Alt+X | 排版并导出 |
| Alt+D | 删除银行信息组 |
| 回车键 | 智能导航（输入框 → 下一个输入框 → 导出按钮） |
| 方向键 | 在各个输入框和按钮间切换 |
| Alt+O | 确定/覆盖（弹窗） |
| Alt+S | 另存为（弹窗） |
| Alt+C | 取消/关闭（弹窗） |
