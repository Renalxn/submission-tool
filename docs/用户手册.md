# 投稿排版助手 - 使用说明

## 简介

投稿排版助手是一款纯本地桌面工具，帮助您快速将文章按投稿规范排版。
- 不联网，保护隐私
- 自动识别标题、作者
- 一键生成 .docx 和 .txt 格式
- 自动记忆联系信息和银行信息

## 安装

### Windows
1. 下载 `投稿排版助手_v1.0.39.exe`
2. 双击运行即可使用
3. 无需安装，可放在任意位置

### macOS
1. 下载 `投稿排版助手_v1.0.39.app`
2. 双击运行
3. 如提示"无法打开"，请前往"系统偏好设置" → "安全性与隐私" → 点击"仍要打开"

### Linux
1. 下载 `投稿排版助手_v1.0.39`
2. 在终端中运行：
   ```bash
   chmod +x 投稿排版助手_v1.0.39
   ./投稿排版助手_v1.0.39
   ```

## 使用步骤

### 1. 选择文件
- 点击"浏览文件"按钮
- 选择 .docx、.txt 或 .md 格式的文件
- **注意：** 不支持旧版 .doc 格式，请先在 Word 中另存为 .docx

### 2. 填写信息
- **标题**：自动从文件第一行识别，可手动修改
- **作者**：自动从文件第二行识别，可手动修改
- **保存文件夹**：选择输出文件的保存位置
- **联系信息**：填写后会自动记忆，下次打开自动填入
- **银行信息**：可添加多组（最多4组），加密保存

### 3. 排版并导出
- 点击"排版并导出"按钮
- 程序会自动创建《标题》投稿文件夹
- 生成两个文件：
  - 《标题》作者.docx
  - 《标题》作者.txt

## 文件格式要求

输入文件结构：
```
第1行：文章标题
第2行：作者姓名
第3行起：正文内容
```

## 常见问题

### Q: 为什么不支持 .doc 格式？
A: .doc 是旧版 Word 格式，需要额外库支持。建议先在 Word 中另存为 .docx 格式。

### Q: 联系信息和银行信息安全吗？
A: 所有敏感信息都加密保存在本地，不会上传到网络。

### Q: 如何清除保存的信息？
A: 删除配置文件目录：
- Windows: `C:\Users\你的用户名\.tougao_assistant\`
- macOS/Linux: `~/.tougao_assistant/`
