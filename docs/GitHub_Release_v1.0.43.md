  - 导航原则：上/左向后，下/右向前；输入框中按回车先跳到按钮，再按才执行

## 主要功能

### 核心功能

- **智能排版**：自动识别标题、作者，按投稿规范排版
- **字数统计**：自动统计正文字数，显示在文末
- **联系信息加密**：姓名、微信、电话、地址、邮编、身份证号、邮箱使用 Fernet 加密存储
- **银行信息加密**：银行名称、账号、开户支行、联行号使用 Fernet 加密存储
- **多格式支持**：支持输入 .docx / .txt / .md 文件，同时输出 .docx 和 .txt

### 排版格式

- **标题**：宋体，4号（14磅），居中，段后无空行
- **作者**：宋体，5号（10.5磅），居中，段后无空行
- **正文**：宋体，5号（10.5磅），两端对齐，段首缩进2字符，单倍行距，段落间无空行
- **字数统计**：宋体，5号（10.5磅），右对齐，正文末尾显示"（正文：xxx 字）"
- **联系信息**：宋体，5号（10.5磅），左对齐
- **银行信息**：宋体，5号（10.5磅），左对齐，最多4组

### 快捷键操作

| 快捷键 | 功能 |
|--------|------|
| 回车键 | 在输入框间智能导航（文件→标题→作者→保存路径→联系信息→银行必填→联行号→导出按钮） |
| 方向键 | 在弹窗的按钮间循环导航（上/左向后，下/右向前） |
| Alt+O | 弹窗中选择"确定/覆盖/重试" |
| Alt+C | 弹窗中选择"取消" |
| Alt+S | 弹窗中选择"另存为" |
