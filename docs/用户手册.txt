投稿排版助手 - 使用说明
========================

简介
----
投稿排版助手是一款纯本地桌面工具，帮助您快速将文章按投稿规范排版。

特点：
- 智能排版：按投稿规范自动排版
- 自动识别：从文件中识别标题、作者
- 字数统计：自动统计正文字数
- 信息记忆：联系信息和银行信息自动记忆
- 多格式支持：支持 .docx / .txt / .md 输入
- 双格式输出：同时生成 .docx 和 .txt
- 快捷键操作：支持快捷键，提升效率
- 不联网：纯本地运行，保护隐私


安装
----

【Windows】
1. 下载 投稿排版助手_v1.0.39.exe
2. 双击运行即可使用
3. 无需安装，可放在任意位置


使用方法
--------

1. 选择文件
   - 点击"浏览文件"按钮
   - 选择 .docx、.txt 或 .md 格式的文件
   - 注意：不支持旧版 .doc 格式，请先在 Word 中另存为 .docx

2. 选择保存文件夹
   - 点击"浏览文件夹"按钮
   - 选择输出文件的保存位置

3. 填写信息
   - 标题：自动从文件第一行识别，可手动修改
   - 作者：自动从文件第二行识别，可手动修改
   - 联系信息：填写后会自动记忆，下次打开自动填入
   - 银行信息：可添加多组（最多4组），加密保存

4. 排版并导出
   - 点击"排版并导出"按钮
   - 程序会自动创建"《标题》投稿"文件夹
   - 生成两个文件：
     * 《标题》作者.docx
     * 《标题》作者.txt

5. 快捷键操作
   - Alt+B：浏览文件
   - Alt+L：浏览文件夹
   - Alt+G：添加银行信息组
   - Alt+X：排版并导出
   - Alt+D：删除银行信息组
   - 回车键：智能导航（输入框 → 下一个输入框 → 导出按钮）
   - 方向键：在各个输入框和按钮间切换
   - Alt+O：确定/覆盖（弹窗）
   - Alt+S：另存为（弹窗）
   - Alt+C：取消/关闭（弹窗）


排版格式说明
------------
排版后的文档格式如下：

【标题】
- 字体：宋体
- 字号：4号（14磅）
- 对齐：居中
- 段后：无空行

【作者】
- 字体：宋体
- 字号：5号（10.5磅）
- 对齐：居中
- 段后：无空行

【正文】
- 字体：宋体
- 字号：5号（10.5磅）
- 对齐：两端对齐
- 段首缩进：2字符
- 行距：单倍行距
- 段落间：无空行

【字数统计】
- 自动统计正文字数（不含标题、作者、空行）
- 在正文末尾显示"（正文：xxx 字）"
- 字体：宋体
- 字号：5号（10.5磅）
- 对齐：右对齐

【联系信息】
- 字体：宋体
- 字号：5号（10.5磅）
- 对齐：左对齐
- 包含以下信息：
  * 姓名
  * 微信
  * 电话
  * 地址
  * 邮编
  * 身份证号
  * 邮箱

【银行信息】
- 字体：宋体
- 字号：5号（10.5磅）
- 对齐：左对齐
- 最多可添加4组
- 每组包含：
  * 银行名称
  * 账号
  * 开户支行
  * 联行号（选填，如收稿方未要求可留空）


原始文件格式要求
----------------
如果您的原始文件符合以下结构，程序将自动识别标题和作者；否则请手动在相应输入框中修改：

  第1行：文章标题
  第2行：作者姓名
  第3行起：正文内容


常见问题
--------

Q: 为什么不支持 .doc 格式？
A: .doc 是旧版 Word 格式，需要额外库支持。建议先在 Word 中另存为 .docx 格式。

Q: 联系信息和银行信息安全吗？
A: 所有敏感信息都加密保存在本地，不会上传到网络。

Q: 如何清除保存的信息？
A: 删除配置文件目录：
   - Windows: C:\Users\你的用户名\.tougao_assistant\

Q: 排版后的文档可以修改吗？
A: 可以。生成的 .docx 文件可以用 Word 打开编辑，.txt 文件可以用记事本编辑。
